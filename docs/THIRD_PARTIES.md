# Third-party services

Static GitHub Pages site. No accounts, forms, cookies, analytics, ads, session replay, or AI features.

| Service | Purpose | Data sent | Disclosure | Can be disabled? |
|---|---|---|---|---|
| GitHub Pages | Hosting (free) | Standard request logs (IP, user agent) held by GitHub | GitHub privacy statement | No (host) |
| Google Fonts (fonts.googleapis.com / fonts.gstatic.com) | Space Grotesk, Inter, JetBrains Mono | Visitor IP + user agent to Google | None on site | Yes: self-host the fonts |
| jsDelivr (cdn.jsdelivr.net) | Motion animation library (`motion@12`) | Visitor IP + user agent to jsDelivr | None on site | Yes: site works without it (`script.js` falls back) |

Outbound links (live product sites, GitHub) are ordinary links; no data is passed.
